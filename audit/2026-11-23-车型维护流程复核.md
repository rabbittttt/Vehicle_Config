# 车型维护流程复核

基线为 `f85ec2b`。本次复核覆盖车型档案、Excel 导入、复制年款、配置矩阵、保存草稿与发布，使用临时数据库和样例工作簿。

| 场景 | 基线问题 | 回归检查 |
| --- | --- | --- |
| 从旧工作簿复制年款 | 版本、选配和发布阶段分别使用编号 `01` 时，复制逻辑混用编号，导致新年款无法保存 | 导入并发布原年款，复制后保存、刷新并发布，核对原记录、新矩阵的标配关系和新阶段的空日期 |
| 编辑带冒号的编号 | 点击 `m1:旧` 会打开 `m1` 的编辑表单 | 在两个编号同时存在时，核对编辑表单中的年款 |
| 维护导入的选配类别 | 导入的自定义类别在编辑和矩阵筛选下拉框中缺失，Excel 模板也会拦截填写 | 使用「舒适/功能」筛选矩阵，打开选配编辑表单并核对类别 |
| 发布草稿 | 预览没有检查过期修订号和缺失的历史编号，可能在确认发布时才报错 | 使用过期修订号、遗漏记录和无效表结构，核对预览、发布错误和数据库版本 |

对应回归用例为 `tests/browser_imported_year.py` 和 `tests/test_catalog.py`。
